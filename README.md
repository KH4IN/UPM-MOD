# UPM-MOD: expansión del Universal Project Mod

Expansión del **Universal Project Mod (UPM)** para Victoria 2, hecha con el permiso de su autor. Se juega sobre **[Project Alice](https://github.com/schombert/Project-Alice)**, el motor abierto de 64 bits que lee los archivos de Victoria 2.

- **Plan completo:** [`PLAN.md`](PLAN.md)
- **Licencias de cada parte:** [`LICENCIAS.md`](LICENCIAS.md)

Este repositorio **no contiene archivos del juego** Victoria 2 ni ningún binario. Para jugar hace falta una copia propia del juego.

## Créditos
- **Universal Project Mod:** su autor original.
- **Project Alice:** schombert y los colaboradores de Project Alice (GPL-3.0).
- **Victoria 2:** Paradox Interactive.
